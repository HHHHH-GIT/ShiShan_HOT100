# 来源与改造

本题改编自 Javis603/token-monitor v0.15.0：
https://github.com/Javis603/token-monitor

主要参考 `src/shared/usage.js` 的设备快照归一化、未采集工具保留、周期判断与汇总流程。题目还保留了原工程中独立的 `limits.js` 与 `history.js` 归一化模块，作为真实项目上下文的一部分；它们不接入本题的报表路径。版权及 MIT 许可全文见 LICENSE。

本地题目移除了桌面壳、真实设备采集、账号连接和云同步，提供内存仓库、回访数据及简化报表。为保留每个工具在共用模型下的可核对依据，输入统一为工具/模型的完整分项。价格、会话历史和真实额度采集不在本题范围内。
