# SHISHAN002 · 共享钱包的两副面孔

## 情景

统一钱包服务供两款游戏使用。星轨提供充值与交易结算，深林提供余额查询。两个游戏里的同一玩家使用同一个钱包。

## 现象

> **工单 #4471 · 两个游戏显示的钱不一样**
>
> 我的账号 P001，在星轨显示 1000.000 元，切到深林显示 1 元。我没有在中间买东西。
>
> —— 玩家 夜航星

> **工单 #4493 · 充值提示到账，重新打开却没变**
>
> 我的账号 P002，充值页面提示成功，显示的余额也增加了。退出页面再进来，看到的却还是之前的数，反复刷新也一样。
>
> —— 玩家 白桦

## 怎么运行

在工程目录执行：

```bash
mvn spring-boot:run
```

- 服务地址：`http://127.0.0.1:18081`；心跳为 `GET /hello`，正常返回 `{"status":"ok"}`。
- 日志位置：`logs/app.log`，路径相对工程运行目录。
- 种子玩家：`P001`（夜航星）、`P002`（白桦），初始余额均为 1000.000 元。
- 单笔充值金额不得超过该玩家当前余额的 10 倍。

## 边界与验收

- 同一玩家在两个游戏中的余额必须一致，单人查询与多人查询遵循相同业务口径。
- 成功充值或交易后，后续查询及对账记录应反映该次变动。
- 保持接口、字段、业务错误响应和金额规则。交易方向 BUY 表示支出，SELL 表示收入。
- 玩家不存在、金额非法、余额不足或超出业务上限时，仍应返回既有业务错误。
